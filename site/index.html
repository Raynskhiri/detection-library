    // how it is built

    One rule, three engines, one truth

    1. Written once. Each detection is a short YAML rule with test events that must fire and must not.
    2. Compiled. Python turns it into Cortex XDR XQL and Splunk SPL, with null guards so missing fields never hide an alert.
    3. Proven three ways. On every push, CI checks the rule, the compiled XQL and SPL, and this page's JavaScript engine against the same 800+ events. They must all agree.
    4. Shipped. Every push to main redeploys this page. Once CI is green, the XQL and SPL packs and the ATT&CK layer are published as a GitHub release.
    Built by Rayen Skhiri, SOC analyst and AppSec engineer. Source and rules on GitHub · MIT · Test events are synthetic.
