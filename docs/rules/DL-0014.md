# DL-0014 · Windows system process name running from the wrong folder

**ATT&CK:** [T1036.005](https://attack.mitre.org/techniques/T1036/005/) · **Tactic:** defense-evasion · **Severity:** high · **Data:** `process_creation`

A process named like a core Windows binary (svchost, lsass, csrss, services, winlogon, smss, wininit, spoolsv, taskhostw) runs from outside System32 or SysWOW64. Malware uses these names to blend into a process list.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter action_process_image_name in ("svchost.exe", "lsass.exe", "csrss.exe", "services.exe", "winlogon.exe", "smss.exe", "wininit.exe", "spoolsv.exe", "taskhostw.exe", "lsm.exe") and not ((action_process_image_path != null and action_process_image_path ~= "(?i)^(\\\\\\\\\\?\\\\)?[a-z]:\\\\windows\\\\(system32|syswow64)\\\\[^\\\\]+$"))
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where (lower(process_name)="svchost.exe" OR lower(process_name)="lsass.exe" OR lower(process_name)="csrss.exe" OR lower(process_name)="services.exe" OR lower(process_name)="winlogon.exe" OR lower(process_name)="smss.exe" OR lower(process_name)="wininit.exe" OR lower(process_name)="spoolsv.exe" OR lower(process_name)="taskhostw.exe" OR lower(process_name)="lsm.exe") AND NOT ((isnotnull(Image) AND match(Image, "(?i)^(\\\\\\\\\\?\\\\)?[a-z]:\\\\windows\\\\(system32|syswow64)\\\\[^\\\\]+$")))
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. Hash the binary and check signature and prevalence.
2. Check its parent, its network connections and how it persists.

## Known false positives

- None expected on a healthy system. Windows itself never runs these from elsewhere.
