# DL-0073 · FortiGate automation stitch, action or auto-script created

**ATT&CK:** [T1053](https://attack.mitre.org/techniques/T1053/), [T1059](https://attack.mitre.org/techniques/T1059/) · **Tactic:** persistence · **Severity:** medium · **Data:** `fortigate`

A new automation stitch, trigger, action or auto-script. These run CLI commands on a schedule or on an event, which makes them a quiet place to hide persistence. The PEERSTITCH operators used an auto-script to download and start their implant, then deleted it. FortiGate event log only.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = fortinet_fortigate_raw
| filter _raw_log != null
| alter fg_logid = arrayindex(regextract(_raw_log, "\\blogid=\"?([^\"\\s]*)"), 0), fg_action = arrayindex(regextract(_raw_log, "\\baction=\"?([^\"\\s]*)"), 0), fg_user = arrayindex(regextract(_raw_log, "\\buser=\"?([^\"\\s]*)"), 0), fg_srcip = arrayindex(regextract(_raw_log, "\\bsrcip=\"?([^\"\\s]*)"), 0), fg_ui = arrayindex(regextract(_raw_log, "\\bui=\"?([^\"\\s]*)"), 0), fg_cfgpath = arrayindex(regextract(_raw_log, "\\bcfgpath=\"?([^\"\\s]*)"), 0), fg_devname = arrayindex(regextract(_raw_log, "\\bdevname=\"?([^\"\\s]*)"), 0), fg_logdesc = arrayindex(regextract(_raw_log, "\\blogdesc=\"([^\"]*)\""), 0), fg_msg = arrayindex(regextract(_raw_log, "\\bmsg=\"([^\"]*)\""), 0)
| filter fg_cfgpath in ("system.automation-stitch", "system.automation-action", "system.automation-trigger", "system.auto-script") and fg_action in ("add", "edit")
| fields _time, fg_devname, fg_logid, fg_user, fg_srcip, fg_ui, fg_logdesc, fg_msg
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`fortigate`
| where (lower(cfgpath)="system.automation-stitch" OR lower(cfgpath)="system.automation-action" OR lower(cfgpath)="system.automation-trigger" OR lower(cfgpath)="system.auto-script") AND (lower(action)="add" OR lower(action)="edit")
| table _time devname logid user srcip ui logdesc msg
| sort - _time
```

## Triage

1. Read the action's script text in the config. Anything that runs execute, fetches a file, or touches /bin is hostile.
2. An auto-script that is added and deleted within minutes is the PEERSTITCH pattern. Check the same window for a new admin (DL-0069) and log changes (DL-0072).

## Known false positives

- Your own stitches (email on admin login, config backup to FortiManager). They change rarely and through a known admin.
