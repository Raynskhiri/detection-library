# DL-0006 · rundll32 runs script or loads from a URL

**ATT&CK:** [T1218.011](https://attack.mitre.org/techniques/T1218/011/) · **Tactic:** execution · **Severity:** high · **Data:** `process_creation`

rundll32 is used to run JavaScript through mshtml (RunHTMLApplication) or to load content from a URL or WebDAV path. Normal rundll32 use names a local DLL and an export.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter action_process_image_name = "rundll32.exe" and (action_process_image_command_line contains "javascript:" or action_process_image_command_line contains "mshtml,runhtmlapplication" or action_process_image_command_line contains "http://" or action_process_image_command_line contains "https://" or action_process_image_command_line contains "@ssl\\davwwwroot")
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where lower(process_name)="rundll32.exe" AND (match(CommandLine, "(?i)javascript:") OR match(CommandLine, "(?i)mshtml,runhtmlapplication") OR match(CommandLine, "(?i)http://") OR match(CommandLine, "(?i)https://") OR match(CommandLine, "(?i)@ssl\\\\davwwwroot"))
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. Identify the DLL or script being loaded and get a copy from the path or URL.
2. Check the parent process to see how rundll32 was launched.

## Known false positives

- Rare. Some printer or update utilities pass a URL as an argument to their own DLL. Allowlist by DLL path.
