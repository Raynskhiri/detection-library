# DL-0001 · PowerShell with an encoded command

**ATT&CK:** [T1059.001](https://attack.mitre.org/techniques/T1059/001/), [T1027](https://attack.mitre.org/techniques/T1027/) · **Tactic:** execution · **Severity:** high · **Data:** `process_creation`

PowerShell started with -EncodedCommand (or any short form PowerShell accepts, such as -enc, -en, -ec or -e) followed by a Base64 blob. Attackers use it to hide the real script from command-line logging and simple string matching. Admin tools rarely need it.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter (action_process_image_name in ("powershell.exe", "pwsh.exe") and action_process_image_command_line ~= "(?i)\\s[-/]e(c|n\\w*)?\\s+[A-Za-z0-9+/]{16,}={0,2}") and not ((actor_process_image_name != null and actor_process_image_name = "ccmexec.exe"))
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where ((lower(process_name)="powershell.exe" OR lower(process_name)="pwsh.exe") AND match(CommandLine, "(?i)\\s[-/]e(c|n\\w*)?\\s+[A-Za-z0-9+/]{16,}={0,2}")) AND NOT ((isnotnull(parent_name) AND lower(parent_name)="ccmexec.exe"))
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. Decode the Base64 (it is UTF-16LE) and read the actual script.
2. Check the parent process. Office, a browser or a script host as parent is a strong signal.
3. Look for network connections and child processes from the same PowerShell process in the next minutes.
4. If the decoded script downloads or runs code, isolate the host and collect the payload.

## Known false positives

- Configuration management agents (SCCM, some RMM tools) that wrap scripts in -EncodedCommand.
- Vendor installers that pass a short encoded bootstrap.
