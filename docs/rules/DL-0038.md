# DL-0038 · Service binary path changed with sc config

**ATT&CK:** [T1574.011](https://attack.mitre.org/techniques/T1574/011/), [T1543.003](https://attack.mitre.org/techniques/T1543/003/) · **Tactic:** privilege-escalation · **Severity:** high · **Data:** `process_creation`

sc config <service> binPath= points an existing service at a new command. With weak service permissions, any user can do this and get code running as SYSTEM on the next service start. PowerUp's Invoke-ServiceAbuse does the same thing.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter (action_process_image_name = "sc.exe" and (action_process_image_command_line contains "config" and action_process_image_command_line contains "binpath")) or (action_process_image_command_line contains "invoke-serviceabuse" or action_process_image_command_line contains "write-servicebinary" or action_process_image_command_line contains "install-servicebinary")
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where (lower(process_name)="sc.exe" AND (match(CommandLine, "(?i)config") AND match(CommandLine, "(?i)binpath"))) OR (match(CommandLine, "(?i)invoke\\-serviceabuse") OR match(CommandLine, "(?i)write\\-servicebinary") OR match(CommandLine, "(?i)install\\-servicebinary"))
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. Read the new binPath. cmd.exe, net.exe or a file in a user-writable folder means abuse.
2. Restore the service config and fix the service ACL (sc sdshow).

## Known false positives

- Software installers reconfiguring their own service. They do not point binPath at cmd.exe or net.exe.
