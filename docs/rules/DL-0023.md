# DL-0023 · Impacket wmiexec or smbexec style command

**ATT&CK:** [T1047](https://attack.mitre.org/techniques/T1047/), [T1021.002](https://attack.mitre.org/techniques/T1021/002/), [T1569.002](https://attack.mitre.org/techniques/T1569/002/) · **Tactic:** lateral-movement · **Severity:** high · **Data:** `process_creation`

cmd.exe /Q /c <command> 1> \\127.0.0.1\ADMIN$\__<timestamp> 2>&1. Impacket's wmiexec and smbexec write command output to the ADMIN$ share this way so they can read it back. The pattern is very specific.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter action_process_image_name = "cmd.exe" and action_process_image_command_line ~= "(?i)\\\\\\\\127\\.0\\.0\\.1\\\\admin\\$\\\\__\\d"
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where lower(process_name)="cmd.exe" AND match(CommandLine, "(?i)\\\\\\\\127\\.0\\.0\\.1\\\\admin\\$\\\\__\\d")
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. Parent wmiprvse.exe means wmiexec; parent services.exe means smbexec. Find the source in network logons.
2. Read every command in the session; they show what the attacker looked for.

## Known false positives

- Authorised penetration tests.
