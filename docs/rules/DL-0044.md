# DL-0044 · Offensive PowerShell toolkit loaded (PowerView, PowerUp, Invoke-Mimikatz)

**ATT&CK:** [T1059.001](https://attack.mitre.org/techniques/T1059/001/), [T1087.002](https://attack.mitre.org/techniques/T1087/002/), [T1003.001](https://attack.mitre.org/techniques/T1003/001/) · **Tactic:** execution · **Severity:** high · **Data:** `windows_event`

Script block logging (4104) shows the functions of well-known offensive toolkits when they are loaded in memory: PowerView, PowerUp, Invoke-Mimikatz, Invoke-Kerberoast, PowerUpSQL, Find-PSRemotingLocalAdminAccess. The command line often shows only IEX or a download cradle.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.EVENT_LOG
| alter evt_subject_user = json_extract_scalar(action_evtlog_data_fields, "$.SubjectUserName"), evt_target_user = json_extract_scalar(action_evtlog_data_fields, "$.TargetUserName"), evt_script_text = json_extract_scalar(action_evtlog_data_fields, "$.ScriptBlockText")
| filter action_evtlog_event_id = 4104 and (evt_script_text contains "find-interestingdomainacl" or evt_script_text contains "invoke-sharefinder" or evt_script_text contains "get-domainobjectacl" or evt_script_text contains "invoke-userhunter" or evt_script_text contains "find-localadminaccess" or evt_script_text contains "invoke-allchecks" or evt_script_text contains "invoke-serviceabuse" or evt_script_text contains "invoke-mimikatz" or evt_script_text contains "invoke-kerberoast" or evt_script_text contains "get-sqlserverlinkcrawl" or evt_script_text contains "get-sqlinstancedomain" or evt_script_text contains "find-psremotinglocaladminaccess" or evt_script_text contains "invoke-portscan" or evt_script_text contains "function get-domainuser")
| fields _time, agent_hostname, action_evtlog_event_id, evt_subject_user, evt_target_user, action_evtlog_message
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`wineventlog`
| where EventCode=4104 AND (match(ScriptBlockText, "(?i)find\\-interestingdomainacl") OR match(ScriptBlockText, "(?i)invoke\\-sharefinder") OR match(ScriptBlockText, "(?i)get\\-domainobjectacl") OR match(ScriptBlockText, "(?i)invoke\\-userhunter") OR match(ScriptBlockText, "(?i)find\\-localadminaccess") OR match(ScriptBlockText, "(?i)invoke\\-allchecks") OR match(ScriptBlockText, "(?i)invoke\\-serviceabuse") OR match(ScriptBlockText, "(?i)invoke\\-mimikatz") OR match(ScriptBlockText, "(?i)invoke\\-kerberoast") OR match(ScriptBlockText, "(?i)get\\-sqlserverlinkcrawl") OR match(ScriptBlockText, "(?i)get\\-sqlinstancedomain") OR match(ScriptBlockText, "(?i)find\\-psremotinglocaladminaccess") OR match(ScriptBlockText, "(?i)invoke\\-portscan") OR match(ScriptBlockText, "(?i)function\\ get\\-domainuser"))
| table _time host EventCode SubjectUserName TargetUserName Message
| sort - _time
```

## Triage

1. Rebuild the full script from consecutive 4104 events (same ScriptBlock ID) to see every function that ran.
2. Look for the AMSI bypass just before it (DL-0043) and the account that ran it.
