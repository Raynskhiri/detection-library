# DL-0004 · mshta runs a remote HTA or inline script

**ATT&CK:** [T1218.005](https://attack.mitre.org/techniques/T1218/005/) · **Tactic:** execution · **Severity:** high · **Data:** `process_creation`

mshta.exe executes an HTA from a URL or inline JavaScript/VBScript. It is a signed Microsoft binary, so it is a favourite way to run script while bypassing application allowlisting.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter action_process_image_name = "mshta.exe" and (action_process_image_command_line contains "http://" or action_process_image_command_line contains "https://" or action_process_image_command_line contains "javascript:" or action_process_image_command_line contains "vbscript:" or action_process_image_command_line contains "about:")
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where lower(process_name)="mshta.exe" AND (match(CommandLine, "(?i)http://") OR match(CommandLine, "(?i)https://") OR match(CommandLine, "(?i)javascript:") OR match(CommandLine, "(?i)vbscript:") OR match(CommandLine, "(?i)about:"))
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. Retrieve the URL or inline script from the command line and analyse it in a sandbox.
2. Check child processes and network connections of mshta.

## Known false positives

- Very old line-of-business apps built on HTA that load pages from an intranet server.
