# DL-0009 · Run key points to a user-writable path or a script host

**ATT&CK:** [T1547.001](https://attack.mitre.org/techniques/T1547/001/) · **Tactic:** persistence · **Severity:** medium · **Data:** `registry_set`

A value is written under ...\CurrentVersion\Run or RunOnce and its data points into AppData, Temp, Public or ProgramData, or launches a script host or LOLBin. This is the most common way commodity malware survives a reboot.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.REGISTRY and event_sub_type = ENUM.REGISTRY_SET_VALUE
| filter action_registry_key_name contains "\\software\\microsoft\\windows\\currentversion\\run" and ((action_registry_data contains "\\appdata\\" or action_registry_data contains "\\temp\\" or action_registry_data contains "\\users\\public\\" or action_registry_data contains "\\programdata\\" or action_registry_data contains "\\downloads\\") or (action_registry_data contains "powershell" or action_registry_data contains "mshta" or action_registry_data contains "wscript" or action_registry_data contains "cscript" or action_registry_data contains "rundll32" or action_registry_data contains "regsvr32" or action_registry_data contains "cmd.exe /c" or action_registry_data contains "cmd /c"))
| fields _time, agent_hostname, actor_process_image_name, action_registry_key_name, action_registry_value_name, action_registry_data
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=13
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), reg_key=replace(TargetObject,"\\\\[^\\\\]*$",""), reg_value=mvindex(split(TargetObject,"\\"),-1)
| where match(reg_key, "(?i)\\\\software\\\\microsoft\\\\windows\\\\currentversion\\\\run") AND ((match(Details, "(?i)\\\\appdata\\\\") OR match(Details, "(?i)\\\\temp\\\\") OR match(Details, "(?i)\\\\users\\\\public\\\\") OR match(Details, "(?i)\\\\programdata\\\\") OR match(Details, "(?i)\\\\downloads\\\\")) OR (match(Details, "(?i)powershell") OR match(Details, "(?i)mshta") OR match(Details, "(?i)wscript") OR match(Details, "(?i)cscript") OR match(Details, "(?i)rundll32") OR match(Details, "(?i)regsvr32") OR match(Details, "(?i)cmd\\.exe\\ /c") OR match(Details, "(?i)cmd\\ /c")))
| table _time host Image TargetObject Details
| sort - _time
```

## Triage

1. Check the binary or script the value points to (signature, hash, age, prevalence across the fleet).
2. Identify the process that wrote the value and its own origin.
3. Remove the value only after collecting the payload.

## Known false positives

- Per-user installs (Teams, Zoom, OneDrive, Discord, Spotify) live in AppData. Allowlist by signer and exact path.
