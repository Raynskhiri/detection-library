# DL-0037 · Account added to the local Administrators group from the command line

**ATT&CK:** [T1098](https://attack.mitre.org/techniques/T1098/) · **Tactic:** persistence · **Severity:** high · **Data:** `process_creation`

net localgroup administrators <user> /add, or Add-LocalGroupMember. Local privilege escalation exploits (for example a service abuse with PowerUp) often end with exactly this command run as SYSTEM.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter (action_process_image_name in ("net.exe", "net1.exe") and (action_process_image_command_line contains "localgroup" and action_process_image_command_line contains "administrators" and action_process_image_command_line contains "/add")) or (action_process_image_command_line contains "add-localgroupmember" and action_process_image_command_line contains "administrators")
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where ((lower(process_name)="net.exe" OR lower(process_name)="net1.exe") AND (match(CommandLine, "(?i)localgroup") AND match(CommandLine, "(?i)administrators") AND match(CommandLine, "(?i)/add"))) OR (match(CommandLine, "(?i)add\\-localgroupmember") AND match(CommandLine, "(?i)administrators"))
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. Check the parent. services.exe or a vulnerable service binary as parent means local privilege escalation through a service.
2. Remove the account from the group and find how it got SYSTEM.

## Known false positives

- Build scripts and helpdesk tools that grant local admin. They run from known parents and accounts.
