# DL-0042 · LSA protection or credential caching weakened in the registry

**ATT&CK:** [T1562.001](https://attack.mitre.org/techniques/T1562/001/), [T1003.001](https://attack.mitre.org/techniques/T1003/001/) · **Tactic:** defense-evasion · **Severity:** high · **Data:** `registry_set`

Turning RunAsPPL off lets tools read LSASS memory again, and UseLogonCredential = 1 makes WDigest keep cleartext passwords in memory. Both prepare a host for credential theft.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.REGISTRY and event_sub_type = ENUM.REGISTRY_SET_VALUE
| filter (action_registry_key_name ~= "(?i)\\\\Control\\\\Lsa$" and action_registry_value_name in ("runasppl", "runaspplboot") and action_registry_data contains "0x00000000") or (action_registry_key_name ~= "(?i)\\\\SecurityProviders\\\\WDigest$" and action_registry_value_name = "uselogoncredential" and action_registry_data contains "0x00000001")
| fields _time, agent_hostname, actor_process_image_name, action_registry_key_name, action_registry_value_name, action_registry_data
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=13
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), reg_key=replace(TargetObject,"\\\\[^\\\\]*$",""), reg_value=mvindex(split(TargetObject,"\\"),-1)
| where (match(reg_key, "(?i)\\\\Control\\\\Lsa$") AND (lower(reg_value)="runasppl" OR lower(reg_value)="runaspplboot") AND match(Details, "(?i)0x00000000")) OR (match(reg_key, "(?i)\\\\SecurityProviders\\\\WDigest$") AND lower(reg_value)="uselogoncredential" AND match(Details, "(?i)0x00000001"))
| table _time host Image TargetObject Details
| sort - _time
```

## Triage

1. Put the value back and reboot. Assume credentials on this host after the change are exposed.

## Known false positives

- Compatibility changes for old LSA plugins. These should be rare and change-managed.
