# DL-0008 · WMIC creates a process, locally or on another host

**ATT&CK:** [T1047](https://attack.mitre.org/techniques/T1047/) · **Tactic:** execution · **Severity:** medium · **Data:** `process_creation`

wmic process call create starts a program through WMI. With /node it runs on a remote machine, which is a common lateral movement method. Admins mostly use other tools today.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter action_process_image_name = "wmic.exe" and (action_process_image_command_line contains "process" and action_process_image_command_line contains "call" and action_process_image_command_line contains "create")
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where lower(process_name)="wmic.exe" AND (match(CommandLine, "(?i)process") AND match(CommandLine, "(?i)call") AND match(CommandLine, "(?i)create"))
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. Note any /node target and check that host for the started process.
2. Confirm the account and whether it normally administers that host.

## Known false positives

- Older admin scripts and some software deployment tools.
