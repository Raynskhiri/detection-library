# DL-0065 · PHP file written in the web root by the web server or PHP worker

**ATT&CK:** [T1505.003](https://attack.mitre.org/techniques/T1505/003/) · **Tactic:** persistence · **Severity:** medium · **Data:** `file_event`

The web server or PHP worker creating a .php, .phtml or .phar file under the web root. After remote code execution, attackers drop a web shell so they can come back even after the bug is patched.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.FILE and event_sub_type in (ENUM.FILE_CREATE_NEW, ENUM.FILE_WRITE)
| filter actor_process_image_path ~= "(?i)/(apache2|httpd|nginx|php-fpm[0-9.]*|php-cgi[0-9.]*|frankenphp|lsphp[0-9]*|dash|sh|bash|curl|wget)$" and action_file_path ~= "(?i)^/(var/www|srv/www|srv/http|usr/share/nginx)/.+\\.(php[0-9]?|phtml|phar|pht)$"
| fields _time, agent_hostname, actor_process_image_name, action_file_path
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=11
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), file_name=lower(mvindex(split(TargetFilename,"\\"),-1))
| where match(Image, "(?i)/(apache2|httpd|nginx|php-fpm[0-9.]*|php-cgi[0-9.]*|frankenphp|lsphp[0-9]*|dash|sh|bash|curl|wget)$") AND match(TargetFilename, "(?i)^/(var/www|srv/www|srv/http|usr/share/nginx)/.+\\.(php[0-9]?|phtml|phar|pht)$")
| table _time host Image TargetFilename
| sort - _time
```

## Triage

1. Open the file. Short files with eval, base64_decode, system, passthru or assert are web shells.
2. Find the first request that hit the new file in the access log; that source IP is the attacker.

## Known false positives

- CMS core and plugin updates (WordPress, Drupal) written by the PHP worker. Correlate with an update in the admin panel.
