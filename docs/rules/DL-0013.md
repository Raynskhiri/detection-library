# DL-0013 · Windows event logs cleared from the command line

**ATT&CK:** [T1070.001](https://attack.mitre.org/techniques/T1070/001/) · **Tactic:** defense-evasion · **Severity:** high · **Data:** `process_creation`

wevtutil cl, Clear-EventLog, Remove-EventLog or the .NET ClearLog call wipe event logs to destroy evidence. Admins very rarely clear logs by hand.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter (action_process_image_name = "wevtutil.exe" and action_process_image_command_line ~= "(?i)\\s(cl|clear-log)\\s") or (action_process_image_name in ("powershell.exe", "pwsh.exe") and (action_process_image_command_line contains "clear-eventlog" or action_process_image_command_line contains "remove-eventlog" or action_process_image_command_line contains "clearlog"))
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where (lower(process_name)="wevtutil.exe" AND match(CommandLine, "(?i)\\s(cl|clear-log)\\s")) OR ((lower(process_name)="powershell.exe" OR lower(process_name)="pwsh.exe") AND (match(CommandLine, "(?i)clear\\-eventlog") OR match(CommandLine, "(?i)remove\\-eventlog") OR match(CommandLine, "(?i)clearlog")))
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. Look for event 1102 (Security log cleared) and 104 (System log cleared) from the same time.
2. Pull logs from the SIEM or EDR for the period before the wipe, they are still there.

## Known false positives

- Lab or golden-image build scripts that reset logs before sealing an image.
