# DL-0030 · PowerView or PowerSploit AD recon functions on the command line

**ATT&CK:** [T1087.002](https://attack.mitre.org/techniques/T1087/002/), [T1069.002](https://attack.mitre.org/techniques/T1069/002/), [T1482](https://attack.mitre.org/techniques/T1482/), [T1135](https://attack.mitre.org/techniques/T1135/) · **Tactic:** discovery · **Severity:** high · **Data:** `process_creation`

PowerView and PowerSploit functions that map users, groups, ACLs, sessions, shares, local admin access and trusts (Get-DomainUser, Find-InterestingDomainAcl, Invoke-ShareFinder, Find-LocalAdminAccess, Get-DomainTrust...). In an AD intrusion this is the step that finds the path to Domain Admin.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter action_process_image_command_line contains "get-domainuser" or action_process_image_command_line contains "get-domaingroupmember" or action_process_image_command_line contains "get-domaincomputer" or action_process_image_command_line contains "get-domainobjectacl" or action_process_image_command_line contains "find-interestingdomainacl" or action_process_image_command_line contains "invoke-sharefinder" or action_process_image_command_line contains "find-localadminaccess" or action_process_image_command_line contains "find-domainuserlocation" or action_process_image_command_line contains "invoke-userhunter" or action_process_image_command_line contains "get-domaintrust" or action_process_image_command_line contains "get-forestdomain" or action_process_image_command_line contains "get-domaingpo" or action_process_image_command_line contains "get-netsession" or action_process_image_command_line contains "get-netloggedon" or action_process_image_command_line contains "find-psremotinglocaladminaccess" or action_process_image_command_line contains "find-wmilocaladminaccess" or action_process_image_command_line contains "get-domainforeigngroupmember"
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where match(CommandLine, "(?i)get\\-domainuser") OR match(CommandLine, "(?i)get\\-domaingroupmember") OR match(CommandLine, "(?i)get\\-domaincomputer") OR match(CommandLine, "(?i)get\\-domainobjectacl") OR match(CommandLine, "(?i)find\\-interestingdomainacl") OR match(CommandLine, "(?i)invoke\\-sharefinder") OR match(CommandLine, "(?i)find\\-localadminaccess") OR match(CommandLine, "(?i)find\\-domainuserlocation") OR match(CommandLine, "(?i)invoke\\-userhunter") OR match(CommandLine, "(?i)get\\-domaintrust") OR match(CommandLine, "(?i)get\\-forestdomain") OR match(CommandLine, "(?i)get\\-domaingpo") OR match(CommandLine, "(?i)get\\-netsession") OR match(CommandLine, "(?i)get\\-netloggedon") OR match(CommandLine, "(?i)find\\-psremotinglocaladminaccess") OR match(CommandLine, "(?i)find\\-wmilocaladminaccess") OR match(CommandLine, "(?i)get\\-domainforeigngroupmember")
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. Find out how PowerView got there. It is usually loaded in memory, so check PowerShell 4104 script blocks (DL-0044) on the same host.
2. {'Look at what came next from the same account': 'ACL changes (DL-0034, 5136 events), new logons on servers, Kerberos ticket requests.'}

## Known false positives

- Authorised penetration tests. Some AD audit scripts reuse PowerView function names.
