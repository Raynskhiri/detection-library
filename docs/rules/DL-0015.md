# DL-0015 · certutil used to download or decode a file

**ATT&CK:** [T1105](https://attack.mitre.org/techniques/T1105/), [T1140](https://attack.mitre.org/techniques/T1140/) · **Tactic:** defense-evasion · **Severity:** high · **Data:** `process_creation`

certutil -urlcache, -verifyctl or -decode used as a downloader or Base64 decoder. A signed Microsoft tool doing a job it was not made for.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter action_process_image_name = "certutil.exe" and (action_process_image_command_line contains "urlcache" or action_process_image_command_line contains "verifyctl" or action_process_image_command_line contains "-decode" or action_process_image_command_line contains "/decode" or action_process_image_command_line contains "-decodehex" or action_process_image_command_line contains "/decodehex")
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where lower(process_name)="certutil.exe" AND (match(CommandLine, "(?i)urlcache") OR match(CommandLine, "(?i)verifyctl") OR match(CommandLine, "(?i)\\-decode") OR match(CommandLine, "(?i)/decode") OR match(CommandLine, "(?i)\\-decodehex") OR match(CommandLine, "(?i)/decodehex"))
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. Retrieve the downloaded or decoded file from the path in the command line.
2. Check what ran it next.

## Known false positives

- PKI admins clearing the URL cache (certutil -urlcache * delete). Check for a URL in the command line.
