# DL-0018 · Kerberoasting or AS-REP roasting tool run

**ATT&CK:** [T1558.003](https://attack.mitre.org/techniques/T1558/003/), [T1558.004](https://attack.mitre.org/techniques/T1558/004/) · **Tactic:** credential-access · **Severity:** high · **Data:** `process_creation`

Command lines of Rubeus, PowerView, Invoke-Kerberoast or Impacket GetUserSPNs / GetNPUsers requesting service tickets or AS-REPs to crack offline. Any domain user can do this, so it is one of the first steps after an initial foothold in AD.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter action_process_image_command_line contains "kerberoast" or action_process_image_command_line contains "asreproast" or action_process_image_command_line contains "get-domainspnticket" or action_process_image_command_line contains "request-spnticket" or action_process_image_command_line contains "getuserspns" or action_process_image_command_line contains "getnpusers" or action_process_image_command_line contains "/format:hashcat"
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where match(CommandLine, "(?i)kerberoast") OR match(CommandLine, "(?i)asreproast") OR match(CommandLine, "(?i)get\\-domainspnticket") OR match(CommandLine, "(?i)request\\-spnticket") OR match(CommandLine, "(?i)getuserspns") OR match(CommandLine, "(?i)getnpusers") OR match(CommandLine, "(?i)/format:hashcat")
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. Pair it with Windows event 4769 on the DCs (many TGS requests with RC4, 0x17) from the same account.
2. Rotate the passwords of the targeted service accounts and move them to long random passwords or gMSA.
