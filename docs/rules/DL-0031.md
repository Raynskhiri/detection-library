# DL-0031 · Rubeus requests, forges or injects Kerberos tickets

**ATT&CK:** [T1558](https://attack.mitre.org/techniques/T1558/), [T1550.003](https://attack.mitre.org/techniques/T1550/003/), [T1550.002](https://attack.mitre.org/techniques/T1550/002/) · **Tactic:** credential-access · **Severity:** critical · **Data:** `process_creation`

Rubeus verbs used after the first foothold: asktgt with a hash or key (overpass-the-hash), s4u (delegation abuse), ptt (pass-the-ticket), tgtdeleg, golden, silver and diamond ticket forging, and monitor (catching TGTs on a host with unconstrained delegation). Also catches Rubeus run through an in-memory loader, since the arguments stay on the command line.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter action_process_image_command_line ~= "(?i)\\b(asktgt|asktgs|s4u|ptt|tgtdeleg|golden|silver|diamond|monitor|harvest|dump|triage|createnetonly|renew)\\b" and ((action_process_image_command_line contains "/rc4:" or action_process_image_command_line contains "/aes256:" or action_process_image_command_line contains "/aes128:" or action_process_image_command_line contains "/ticket:" or action_process_image_command_line contains "/impersonateuser:" or action_process_image_command_line contains "/msdsspn:" or action_process_image_command_line contains "/certificate:" or action_process_image_command_line contains "/krbkey:" or action_process_image_command_line contains "/ptt" or action_process_image_command_line contains "/nowrap" or action_process_image_command_line contains "/interval:") or action_process_image_command_line contains "rubeus")
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where match(CommandLine, "(?i)\\b(asktgt|asktgs|s4u|ptt|tgtdeleg|golden|silver|diamond|monitor|harvest|dump|triage|createnetonly|renew)\\b") AND ((match(CommandLine, "(?i)/rc4:") OR match(CommandLine, "(?i)/aes256:") OR match(CommandLine, "(?i)/aes128:") OR match(CommandLine, "(?i)/ticket:") OR match(CommandLine, "(?i)/impersonateuser:") OR match(CommandLine, "(?i)/msdsspn:") OR match(CommandLine, "(?i)/certificate:") OR match(CommandLine, "(?i)/krbkey:") OR match(CommandLine, "(?i)/ptt") OR match(CommandLine, "(?i)/nowrap") OR match(CommandLine, "(?i)/interval:")) OR match(CommandLine, "(?i)rubeus"))
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. /rc4: or /aes256: means a stolen key is being used: find where it came from (LSASS dump, DCSync) and reset that account.
2. s4u with /impersonateuser points to delegation abuse: check msDS-AllowedToActOnBehalfOfOtherIdentity and msDS-AllowedToDelegateTo on the target service.
3. golden, silver or diamond means forged tickets. Plan a double krbtgt reset if krbtgt keys were exposed.

## Known false positives

- Red team exercises. klist and normal Kerberos use do not match.
