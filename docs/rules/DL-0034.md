# DL-0034 · AD object rights or memberships changed with PowerView or StandIn

**ATT&CK:** [T1098](https://attack.mitre.org/techniques/T1098/) · **Tactic:** privilege-escalation · **Severity:** high · **Data:** `process_creation`

Write actions from PowerView and StandIn: granting rights on an object (Add-DomainObjectAcl, including DCSync rights), setting attributes (Set-DomainObject), adding group members, resetting passwords, or writing resource-based constrained delegation (StandIn --computer --sid). These turn a weak ACL into a working escalation path.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter (action_process_image_command_line contains "add-domainobjectacl" or action_process_image_command_line contains "set-domainobject" or action_process_image_command_line contains "add-domaingroupmember" or action_process_image_command_line contains "set-domainuserpassword" or action_process_image_command_line contains "set-domainobjectowner" or action_process_image_command_line contains "add-objectacl") or (action_process_image_command_line contains "standin" and action_process_image_command_line ~= "(?i)(--computer\\b.*--sid|--group\\b.*--add|--setuserrights|--grant|--spn|--setpassword)")
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where (match(CommandLine, "(?i)add\\-domainobjectacl") OR match(CommandLine, "(?i)set\\-domainobject") OR match(CommandLine, "(?i)add\\-domaingroupmember") OR match(CommandLine, "(?i)set\\-domainuserpassword") OR match(CommandLine, "(?i)set\\-domainobjectowner") OR match(CommandLine, "(?i)add\\-objectacl")) OR (match(CommandLine, "(?i)standin") AND match(CommandLine, "(?i)(--computer\\b.*--sid|--group\\b.*--add|--setuserrights|--grant|--spn|--setpassword)"))
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. On the DC, find the matching 5136 (attribute changed) or 4728/4732/4756 (member added) events and the object that changed.
2. Undo the change, then look for what the attacker did with it next (new delegation, DCSync, password reset logon).

## Known false positives

- AD administrators using PowerView in scripts. Uncommon; most admins use the ActiveDirectory module.
