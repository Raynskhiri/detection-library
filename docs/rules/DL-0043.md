# DL-0043 · AMSI or ETW bypass in a PowerShell script block

**ATT&CK:** [T1562.001](https://attack.mitre.org/techniques/T1562/001/) · **Tactic:** defense-evasion · **Severity:** high · **Data:** `windows_event`

PowerShell script block logging (event 4104) records the code PowerShell actually ran, after decoding. Bypasses that switch off AMSI (amsiInitFailed, AmsiScanBuffer patching, amsi.dll tricks) or blind ETW (EtwEventWrite, PSEtwLogProvider) leave their strings here, even when the command line is obfuscated.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.EVENT_LOG
| alter evt_subject_user = json_extract_scalar(action_evtlog_data_fields, "$.SubjectUserName"), evt_target_user = json_extract_scalar(action_evtlog_data_fields, "$.TargetUserName"), evt_script_text = json_extract_scalar(action_evtlog_data_fields, "$.ScriptBlockText")
| filter action_evtlog_event_id = 4104 and (evt_script_text contains "amsiinitfailed" or evt_script_text contains "amsiscanbuffer" or evt_script_text contains "amsiutils" or evt_script_text contains "amsicontext" or evt_script_text contains "amsiopensession" or evt_script_text contains "amsi.dll" or evt_script_text contains "etweventwrite" or evt_script_text contains "psetwlogprovider" or evt_script_text contains "cachedgrouppolicysettings")
| fields _time, agent_hostname, action_evtlog_event_id, evt_subject_user, evt_target_user, action_evtlog_message
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`wineventlog`
| where EventCode=4104 AND (match(ScriptBlockText, "(?i)amsiinitfailed") OR match(ScriptBlockText, "(?i)amsiscanbuffer") OR match(ScriptBlockText, "(?i)amsiutils") OR match(ScriptBlockText, "(?i)amsicontext") OR match(ScriptBlockText, "(?i)amsiopensession") OR match(ScriptBlockText, "(?i)amsi\\.dll") OR match(ScriptBlockText, "(?i)etweventwrite") OR match(ScriptBlockText, "(?i)psetwlogprovider") OR match(ScriptBlockText, "(?i)cachedgrouppolicysettings"))
| table _time host EventCode SubjectUserName TargetUserName Message
| sort - _time
```

## Triage

1. Read the next script blocks from the same host and session. The bypass is the first step; the tool loaded after it is the real payload (DL-0044).
2. Check if the user also set COR_PROFILER (DL-0040) to hide later activity.

## Known false positives

- Security tools and training material that mention AMSI. Real bypasses use reflection on these names.
