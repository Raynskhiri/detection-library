# DL-0019 · Mimikatz modules on the command line

**ATT&CK:** [T1003.001](https://attack.mitre.org/techniques/T1003/001/), [T1003.006](https://attack.mitre.org/techniques/T1003/006/), [T1550.002](https://attack.mitre.org/techniques/T1550/002/), [T1558.001](https://attack.mitre.org/techniques/T1558/001/) · **Tactic:** credential-access · **Severity:** critical · **Data:** `process_creation`

Command lines with Mimikatz module syntax (sekurlsa::, lsadump::, kerberos::, token::, dpapi::, privilege::debug), including when the binary is renamed or run through PowerShell (Invoke-Mimikatz).

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter action_process_image_command_line contains "sekurlsa::" or action_process_image_command_line contains "lsadump::" or action_process_image_command_line contains "kerberos::" or action_process_image_command_line contains "token::elevate" or action_process_image_command_line contains "dpapi::" or action_process_image_command_line contains "privilege::debug" or action_process_image_command_line contains "crypto::" or action_process_image_command_line contains "invoke-mimikatz"
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where match(CommandLine, "(?i)sekurlsa::") OR match(CommandLine, "(?i)lsadump::") OR match(CommandLine, "(?i)kerberos::") OR match(CommandLine, "(?i)token::elevate") OR match(CommandLine, "(?i)dpapi::") OR match(CommandLine, "(?i)privilege::debug") OR match(CommandLine, "(?i)crypto::") OR match(CommandLine, "(?i)invoke\\-mimikatz")
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. lsadump::dcsync or lsadump::lsa on a DC means domain compromise. Escalate immediately.
2. kerberos::golden or ::ptt means forged or injected tickets. Plan a double krbtgt reset.
3. Reset every credential that was on the host.

## Known false positives

- Authorised red team activity.
