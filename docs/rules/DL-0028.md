# DL-0028 · rclone copies data to a remote

**ATT&CK:** [T1567.002](https://attack.mitre.org/techniques/T1567/002/), [T1048](https://attack.mitre.org/techniques/T1048/) · **Tactic:** exfiltration · **Severity:** high · **Data:** `process_creation`

rclone (often renamed) syncing or copying folders to cloud storage, MEGA, FTP or WebDAV. It is the most used exfiltration tool in ransomware intrusions because it is fast and looks like backup traffic.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter action_process_image_command_line ~= "(?i)\\s(copy|copyto|sync|move)\\s" and (action_process_image_name = "rclone.exe" or (action_process_image_command_line contains "--multi-thread-streams" or action_process_image_command_line contains "--no-check-certificate" or action_process_image_command_line contains "--transfers" or action_process_image_command_line contains "--ignore-existing" or action_process_image_command_line contains "--max-age" or action_process_image_command_line contains "--auto-confirm"))
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where match(CommandLine, "(?i)\\s(copy|copyto|sync|move)\\s") AND (lower(process_name)="rclone.exe" OR (match(CommandLine, "(?i)\\-\\-multi\\-thread\\-streams") OR match(CommandLine, "(?i)\\-\\-no\\-check\\-certificate") OR match(CommandLine, "(?i)\\-\\-transfers") OR match(CommandLine, "(?i)\\-\\-ignore\\-existing") OR match(CommandLine, "(?i)\\-\\-max\\-age") OR match(CommandLine, "(?i)\\-\\-auto\\-confirm")))
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. Read the remote name and find the rclone.conf to learn the destination and credentials.
2. Measure how much data left (proxy or firewall bytes out) and which folders were copied.

## Known false positives

- IT backup jobs that use rclone on purpose. These should run from a fixed path and account.
