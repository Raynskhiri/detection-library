# DL-0032 · AD CS abuse tool looks for or requests vulnerable certificates

**ATT&CK:** [T1649](https://attack.mitre.org/techniques/T1649/) · **Tactic:** credential-access · **Severity:** high · **Data:** `process_creation`

Certify, Certipy and ForgeCert used to find vulnerable certificate templates (ESC1 to ESC8), request a certificate as another user, or forge one with a stolen CA key. A certificate gives a login that survives password resets.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter ((action_process_image_command_line contains "certify" and action_process_image_command_line ~= "(?i)\\b(find|request|download|cas|pkiobjects)\\b") or (action_process_image_command_line contains "certipy" and action_process_image_command_line ~= "(?i)\\b(find|req|auth|shadow|forge|ca)\\b")) or (action_process_image_command_line contains "forgecert" or action_process_image_command_line contains "/onbehalfof:" or action_process_image_command_line contains "/altname:" or action_process_image_command_line contains "-upn ")
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where ((match(CommandLine, "(?i)certify") AND match(CommandLine, "(?i)\\b(find|request|download|cas|pkiobjects)\\b")) OR (match(CommandLine, "(?i)certipy") AND match(CommandLine, "(?i)\\b(find|req|auth|shadow|forge|ca)\\b"))) OR (match(CommandLine, "(?i)forgecert") OR match(CommandLine, "(?i)/onbehalfof:") OR match(CommandLine, "(?i)/altname:") OR match(CommandLine, "(?i)\\-upn\\ "))
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. Check CA events 4886 and 4887 for certificates issued to the same requester around that time (DL-0061).
2. Revoke any certificate issued to a privileged account that was not expected, and fix the template (enrollment rights, ENROLLEE_SUPPLIES_SUBJECT, Certificate Request Agent EKU).

## Known false positives

- PKI admins auditing templates with Certify or Certipy find. Confirm with the PKI team.
