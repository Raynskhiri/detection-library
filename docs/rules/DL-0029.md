# DL-0029 · Shadow copies, backups or boot recovery removed

**ATT&CK:** [T1490](https://attack.mitre.org/techniques/T1490/) · **Tactic:** impact · **Severity:** critical · **Data:** `process_creation`

vssadmin or WMI deleting shadow copies, shrinking shadow storage, wbadmin deleting the backup catalog, or bcdedit disabling recovery. Ransomware does this minutes before or during encryption so the victim cannot roll back.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter ((((action_process_image_name = "vssadmin.exe" and action_process_image_command_line ~= "(?i)(delete\\s+shadows|resize\\s+shadowstorage)") or (action_process_image_name = "wmic.exe" and (action_process_image_command_line contains "shadowcopy" and action_process_image_command_line contains "delete"))) or (action_process_image_name in ("powershell.exe", "pwsh.exe") and (action_process_image_command_line contains "win32_shadowcopy" and action_process_image_command_line contains "delete"))) or (action_process_image_name = "wbadmin.exe" and action_process_image_command_line ~= "(?i)delete\\s+(catalog|systemstatebackup|backup)")) or (action_process_image_name = "bcdedit.exe" and (action_process_image_command_line contains "recoveryenabled no" or action_process_image_command_line contains "bootstatuspolicy ignoreallfailures"))
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where ((((lower(process_name)="vssadmin.exe" AND match(CommandLine, "(?i)(delete\\s+shadows|resize\\s+shadowstorage)")) OR (lower(process_name)="wmic.exe" AND (match(CommandLine, "(?i)shadowcopy") AND match(CommandLine, "(?i)delete")))) OR ((lower(process_name)="powershell.exe" OR lower(process_name)="pwsh.exe") AND (match(CommandLine, "(?i)win32_shadowcopy") AND match(CommandLine, "(?i)delete")))) OR (lower(process_name)="wbadmin.exe" AND match(CommandLine, "(?i)delete\\s+(catalog|systemstatebackup|backup)"))) OR (lower(process_name)="bcdedit.exe" AND (match(CommandLine, "(?i)recoveryenabled\\ no") OR match(CommandLine, "(?i)bootstatuspolicy\\ ignoreallfailures")))
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. Treat as active ransomware. Isolate the host now, then investigate.
2. Check other hosts for the same command in the same minutes; it is usually pushed everywhere at once.

## Known false positives

- Backup software rotating its own shadow copies (usually through the VSS API, not vssadmin).
