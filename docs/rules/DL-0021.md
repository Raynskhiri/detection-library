# DL-0021 · BloodHound collector (SharpHound) run

**ATT&CK:** [T1087.002](https://attack.mitre.org/techniques/T1087/002/), [T1069.002](https://attack.mitre.org/techniques/T1069/002/), [T1482](https://attack.mitre.org/techniques/T1482/) · **Tactic:** discovery · **Severity:** high · **Data:** `process_creation`

SharpHound or Invoke-BloodHound collects sessions, ACLs, group membership and trusts so an attacker can graph a path to Domain Admin.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter action_process_image_name = "sharphound.exe" or (action_process_image_command_line contains "sharphound" or action_process_image_command_line contains "invoke-bloodhound" or action_process_image_command_line contains "collectionmethod" or action_process_image_command_line contains "bloodhound.py" or action_process_image_command_line contains "--zipfilename")
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where lower(process_name)="sharphound.exe" OR (match(CommandLine, "(?i)sharphound") OR match(CommandLine, "(?i)invoke\\-bloodhound") OR match(CommandLine, "(?i)collectionmethod") OR match(CommandLine, "(?i)bloodhound\\.py") OR match(CommandLine, "(?i)\\-\\-zipfilename"))
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. Find the output ZIP (usually in the working directory) and check if it left the host.
2. Expect LDAP and SMB session enumeration against many hosts from this machine at the same time.

## Known false positives

- Authorised AD security assessments, which should be scheduled and known.
