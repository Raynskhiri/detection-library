# DL-0062 · Remote access to the print spooler or EFS pipe (authentication coercion)

**ATT&CK:** [T1187](https://attack.mitre.org/techniques/T1187/) · **Tactic:** credential-access · **Severity:** medium · **Data:** `windows_event`

Event 5145 for IPC$ with the spoolss or efsrpc pipe. Printer bug (MS-RPRN) and PetitPotam (MS-EFSR) and DFSCoerce (MS-DFSNM) force a server, often a DC, to authenticate to an attacker-chosen host. With unconstrained delegation on that host, the attacker captures the DC's TGT.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.EVENT_LOG
| alter evt_subject_user = json_extract_scalar(action_evtlog_data_fields, "$.SubjectUserName"), evt_target_user = json_extract_scalar(action_evtlog_data_fields, "$.TargetUserName"), evt_share_name = json_extract_scalar(action_evtlog_data_fields, "$.ShareName"), evt_share_target = json_extract_scalar(action_evtlog_data_fields, "$.RelativeTargetName")
| filter action_evtlog_event_id = 5145 and evt_share_name ~= "(?i)IPC\\$$" and evt_share_target in ("spoolss", "efsrpc", "netdfs")
| fields _time, agent_hostname, action_evtlog_event_id, evt_subject_user, evt_target_user, action_evtlog_message
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`wineventlog`
| where EventCode=5145 AND match(ShareName, "(?i)IPC\\$$") AND (lower(RelativeTargetName)="spoolss" OR lower(RelativeTargetName)="efsrpc" OR lower(RelativeTargetName)="netdfs")
| table _time host EventCode SubjectUserName TargetUserName Message
| sort - _time
```

## Triage

1. Check the source IP. A workstation calling the spooler on a DC is suspicious.
2. Look for a TGT for the DC computer account appearing on another host (Rubeus monitor, DL-0031).

## Known false positives

- Print servers receiving normal spooler traffic. Turn off the spooler on DCs and this becomes quiet there.
