# DL-0075 · MeshAgent or Pulseway started, or a program run from ProgramData\USOShared

**ATT&CK:** [T1219](https://attack.mitre.org/techniques/T1219/), [T1036.005](https://attack.mitre.org/techniques/T1036/005/) · **Tactic:** command-and-control · **Severity:** high · **Data:** `process_creation`

Remote management agents that the IT team did not deploy, or any executable started from C:\ProgramData\USOShared, a Windows Update folder that normally holds logs, not programs. In a 2026 FortiGate intrusion the attackers moved from the firewall to the servers, installed Pulseway and MeshAgent there, and hid MeshAgent from the uninstall list. Full-telemetry tier: needs an EDR on the servers behind the FortiGate.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter action_process_image_name in ("meshagent.exe", "meshagent64.exe", "pcmonitorsrv.exe", "pcmonitormanager.exe", "pulseway.exe") or action_process_image_path ~= "(?i)^c:\\\\programdata\\\\usoshared\\\\"
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where (lower(process_name)="meshagent.exe" OR lower(process_name)="meshagent64.exe" OR lower(process_name)="pcmonitorsrv.exe" OR lower(process_name)="pcmonitormanager.exe" OR lower(process_name)="pulseway.exe") OR match(Image, "(?i)^c:\\\\programdata\\\\usoshared\\\\")
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. Find how the agent arrived (parent process, the logon that started it) and which server it calls home to.
2. Check the uninstall keys for SystemComponent=1 on the same host. A hidden RMM agent is a backdoor.
3. Walk back to the firewall. Look for a FortiGate admin login, config export or new admin in the days before (DL-0068 to DL-0070).

## Known false positives

- An MSP or IT team that really uses MeshCentral or Pulseway. Allow-list the signer and the install path they use.
