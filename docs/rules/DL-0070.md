# DL-0070 · FortiGate configuration backed up or downloaded

**ATT&CK:** [T1552.001](https://attack.mitre.org/techniques/T1552/001/), [T1005](https://attack.mitre.org/techniques/T1005/) · **Tactic:** credential-access · **Severity:** high · **Data:** `fortigate`

The full FortiGate configuration was exported. It holds the LDAP bind account, VPN and admin secrets protected with reversible encryption, plus the network map. In the 2026 campaigns, stealing it was the first thing attackers did, then they decrypted the LDAP service account and walked into Active Directory. FortiGate event log only. Message wording differs a little between FortiOS versions, so the rule matches on the description and the message text.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = fortinet_fortigate_raw
| filter _raw_log != null
| alter fg_logid = arrayindex(regextract(_raw_log, "\\blogid=\"?([^\"\\s]*)"), 0), fg_subtype = arrayindex(regextract(_raw_log, "\\bsubtype=\"?([^\"\\s]*)"), 0), fg_user = arrayindex(regextract(_raw_log, "\\buser=\"?([^\"\\s]*)"), 0), fg_srcip = arrayindex(regextract(_raw_log, "\\bsrcip=\"?([^\"\\s]*)"), 0), fg_ui = arrayindex(regextract(_raw_log, "\\bui=\"?([^\"\\s]*)"), 0), fg_devname = arrayindex(regextract(_raw_log, "\\bdevname=\"?([^\"\\s]*)"), 0), fg_logdesc = arrayindex(regextract(_raw_log, "\\blogdesc=\"([^\"]*)\""), 0), fg_msg = arrayindex(regextract(_raw_log, "\\bmsg=\"([^\"]*)\""), 0)
| filter fg_subtype = "system" and (fg_logdesc ~= "(?i)(backup|back up|backed up|download).*(conf|configuration)|(conf|configuration).*(backup|backed up|download)" or fg_msg ~= "(?i)(backup|back up|backed up|download).*(conf|configuration)|(conf|configuration).*(backup|backed up|download)")
| fields _time, fg_devname, fg_logid, fg_user, fg_srcip, fg_ui, fg_logdesc, fg_msg
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`fortigate`
| where lower(subtype)="system" AND (match(logdesc, "(?i)(backup|back up|backed up|download).*(conf|configuration)|(conf|configuration).*(backup|backed up|download)") OR match(msg, "(?i)(backup|back up|backed up|download).*(conf|configuration)|(conf|configuration).*(backup|backed up|download)"))
| table _time devname logid user srcip ui logdesc msg
| sort - _time
```

## Triage

1. Treat an export by an unexpected user, from an internet IP or right after a new admin (DL-0069) as a credential theft. Rotate every secret in the file - the LDAP or AD bind account first, then VPN pre-shared keys and local user passwords.
2. In AD, review logons by the FortiGate bind account from anywhere other than the FortiGate itself.
3. Exports from the CLI (show full-configuration in the GUI console) do not always log a backup event. Also look for ui=jsconsole sessions from unusual IPs.

## Known false positives

- Scheduled backups by FortiManager or a backup script. They come from one known IP at a fixed time.
- An admin taking a backup before an upgrade. Match it to the change ticket.
