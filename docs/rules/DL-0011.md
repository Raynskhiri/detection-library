# DL-0011 · Service created with a suspicious binary path

**ATT&CK:** [T1543.003](https://attack.mitre.org/techniques/T1543/003/), [T1569.002](https://attack.mitre.org/techniques/T1569/002/) · **Tactic:** persistence · **Severity:** high · **Data:** `process_creation`

sc create registers a service whose binPath runs cmd, PowerShell, a LOLBin or a file from a user-writable folder. Services run as SYSTEM, so this is both persistence and privilege escalation. Remote service creation is also how PsExec-like tools move laterally.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter (action_process_image_name = "sc.exe" and action_process_image_command_line contains " create ") and (action_process_image_command_line contains "\\appdata\\" or action_process_image_command_line contains "\\temp\\" or action_process_image_command_line contains "\\users\\public\\" or action_process_image_command_line contains "\\programdata\\" or action_process_image_command_line contains "powershell" or action_process_image_command_line contains "cmd /c" or action_process_image_command_line contains "cmd.exe /c" or action_process_image_command_line contains "%comspec%" or action_process_image_command_line contains "mshta" or action_process_image_command_line contains "rundll32" or action_process_image_command_line contains "regsvr32")
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where (lower(process_name)="sc.exe" AND match(CommandLine, "(?i)\\ create\\ ")) AND (match(CommandLine, "(?i)\\\\appdata\\\\") OR match(CommandLine, "(?i)\\\\temp\\\\") OR match(CommandLine, "(?i)\\\\users\\\\public\\\\") OR match(CommandLine, "(?i)\\\\programdata\\\\") OR match(CommandLine, "(?i)powershell") OR match(CommandLine, "(?i)cmd\\ /c") OR match(CommandLine, "(?i)cmd\\.exe\\ /c") OR match(CommandLine, "(?i)%comspec%") OR match(CommandLine, "(?i)mshta") OR match(CommandLine, "(?i)rundll32") OR match(CommandLine, "(?i)regsvr32"))
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. Query the service (sc qc <name>) and inspect the binary.
2. If the command targeted another host (sc \\host create), investigate that host too.

## Known false positives

- Installers that create a service from ProgramData. Allowlist by signer.
