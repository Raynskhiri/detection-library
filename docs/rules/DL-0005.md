# DL-0005 · regsvr32 loads a remote scriptlet (Squiblydoo)

**ATT&CK:** [T1218.010](https://attack.mitre.org/techniques/T1218/010/) · **Tactic:** execution · **Severity:** high · **Data:** `process_creation`

regsvr32 with /i:<URL> and scrobj.dll fetches and runs a COM scriptlet from the internet. The technique is called Squiblydoo. Legitimate COM registration never points at a URL.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter action_process_image_name = "regsvr32.exe" and (action_process_image_command_line contains "/i:http" or action_process_image_command_line contains "-i:http" or action_process_image_command_line contains "scrobj.dll" or action_process_image_command_line contains "/i:\\\\" or action_process_image_command_line contains "-i:\\\\")
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where lower(process_name)="regsvr32.exe" AND (match(CommandLine, "(?i)/i:http") OR match(CommandLine, "(?i)\\-i:http") OR match(CommandLine, "(?i)scrobj\\.dll") OR match(CommandLine, "(?i)/i:\\\\\\\\") OR match(CommandLine, "(?i)\\-i:\\\\\\\\"))
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. Pull the scriptlet URL and analyse the .sct content.
2. Check for child processes of regsvr32 and outbound connections.
