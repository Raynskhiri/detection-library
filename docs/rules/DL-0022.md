# DL-0022 · PsExec service runs a command

**ATT&CK:** [T1569.002](https://attack.mitre.org/techniques/T1569/002/), [T1021.002](https://attack.mitre.org/techniques/T1021/002/) · **Tactic:** lateral-movement · **Severity:** medium · **Data:** `process_creation`

PSEXESVC.exe is the service PsExec installs on the target host. A process under it means someone ran a command remotely on this host over SMB.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter action_process_image_name = "psexesvc.exe" or actor_process_image_name = "psexesvc.exe"
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where lower(process_name)="psexesvc.exe" OR lower(parent_name)="psexesvc.exe"
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. Find the source host in the 4624 logon (type 3) and 7045 service install events at the same time.
2. Read the child command line.

## Known false positives

- IT admins who use PsExec for support. Confirm the source host and account.
