# DL-0027 · Script host or LOLBin looks up a paste site, file drop or tunnel service

**ATT&CK:** [T1102](https://attack.mitre.org/techniques/T1102/), [T1105](https://attack.mitre.org/techniques/T1105/), [T1572](https://attack.mitre.org/techniques/T1572/) · **Tactic:** command-and-control · **Severity:** medium · **Data:** `dns_query`

PowerShell, a script host or a LOLBin resolves pastebin, raw GitHub content, a temporary file host, an ngrok or Cloudflare tunnel, Discord CDN or the Telegram bot API. These free services host payloads and act as C2 because they are rarely blocked.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.NETWORK and dns_query_name != null
| filter actor_process_image_name in ("powershell.exe", "pwsh.exe", "wscript.exe", "cscript.exe", "mshta.exe", "rundll32.exe", "regsvr32.exe", "certutil.exe", "bitsadmin.exe", "cmd.exe", "msbuild.exe") and dns_query_name ~= "(?i)(^|\\.)(pastebin\\.com|paste\\.ee|hastebin\\.com|rentry\\.co|raw\\.githubusercontent\\.com|transfer\\.sh|file\\.io|gofile\\.io|temp\\.sh|ngrok\\.io|ngrok-free\\.app|trycloudflare\\.com|cdn\\.discordapp\\.com|api\\.telegram\\.org)\\.?$"
| fields _time, agent_hostname, actor_process_image_name, dns_query_name
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=22
| eval process_name=lower(mvindex(split(Image,"\\"),-1))
| where (lower(process_name)="powershell.exe" OR lower(process_name)="pwsh.exe" OR lower(process_name)="wscript.exe" OR lower(process_name)="cscript.exe" OR lower(process_name)="mshta.exe" OR lower(process_name)="rundll32.exe" OR lower(process_name)="regsvr32.exe" OR lower(process_name)="certutil.exe" OR lower(process_name)="bitsadmin.exe" OR lower(process_name)="cmd.exe" OR lower(process_name)="msbuild.exe") AND match(QueryName, "(?i)(^|\\.)(pastebin\\.com|paste\\.ee|hastebin\\.com|rentry\\.co|raw\\.githubusercontent\\.com|transfer\\.sh|file\\.io|gofile\\.io|temp\\.sh|ngrok\\.io|ngrok-free\\.app|trycloudflare\\.com|cdn\\.discordapp\\.com|api\\.telegram\\.org)\\.?$")
| table _time host Image QueryName
| sort - _time
```

## Triage

1. Find the URL in proxy logs or the process command line and fetch the content safely.
2. Check what the process did after the lookup (new files, child processes).

## Known false positives

- Admin or developer scripts that pull from raw.githubusercontent.com. Allowlist by script and repo.
