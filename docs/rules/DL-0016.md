# DL-0016 · LSASS memory dumped with comsvcs.dll or ProcDump

**ATT&CK:** [T1003.001](https://attack.mitre.org/techniques/T1003/001/) · **Tactic:** credential-access · **Severity:** critical · **Data:** `process_creation`

rundll32 calling the MiniDump export of comsvcs.dll (by name or by ordinal #24), or ProcDump pointed at lsass. Both write the LSASS process memory to disk so passwords, hashes and Kerberos tickets can be extracted offline.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter ((action_process_image_name = "rundll32.exe" and action_process_image_command_line contains "comsvcs") and action_process_image_command_line ~= "(?i)(minidump|#\\+?0*24\\b)") or (action_process_image_name in ("procdump.exe", "procdump64.exe", "procdump64a.exe") and action_process_image_command_line contains "lsass")
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where ((lower(process_name)="rundll32.exe" AND match(CommandLine, "(?i)comsvcs")) AND match(CommandLine, "(?i)(minidump|#\\+?0*24\\b)")) OR ((lower(process_name)="procdump.exe" OR lower(process_name)="procdump64.exe" OR lower(process_name)="procdump64a.exe") AND match(CommandLine, "(?i)lsass"))
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. Find and secure the dump file named in the command line, then delete it.
2. Assume every credential cached on the host is stolen. Reset them, starting with privileged accounts.
3. Hunt for logons from the accounts that were on this host to new places in the following hours.

## Known false positives

- Support engineers capturing an LSASS dump for Microsoft during a case. Should be rare and announced.
