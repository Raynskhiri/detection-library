# DL-0063 · Web server or PHP worker starts a shell or download tool (Linux)

**ATT&CK:** [T1190](https://attack.mitre.org/techniques/T1190/), [T1059.004](https://attack.mitre.org/techniques/T1059/004/), [T1505.003](https://attack.mitre.org/techniques/T1505/003/) · **Tactic:** initial-access · **Severity:** high · **Data:** `process_creation`

Apache, nginx, PHP-FPM, php-cgi, FrankenPHP or LiteSpeed starting sh, bash, curl, wget, netcat, Python or a recon command. This is the most direct sign that a remote code execution bug or a web shell is being used, for example PHP2Shell (CVE-2026-109618 and CVE-2026-109619), where the command runs as the web user (www-data) under the worker.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter (actor_process_image_path ~= "(?i)/(apache2|httpd|nginx|php-fpm[0-9.]*|php-cgi[0-9.]*|frankenphp|lsphp[0-9]*|litespeed|lshttpd)$" and action_process_image_path ~= "(?i)/(sh|bash|dash|zsh|ksh|busybox|nc|ncat|netcat|socat|curl|wget|python[0-9.]*|perl|ruby|id|whoami|uname|hostname|base64|chmod)$") and not ((action_process_image_command_line != null and (action_process_image_command_line contains "sendmail" or action_process_image_command_line contains "/usr/sbin/exim" or action_process_image_command_line contains "postdrop")))
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where (match(ParentImage, "(?i)/(apache2|httpd|nginx|php-fpm[0-9.]*|php-cgi[0-9.]*|frankenphp|lsphp[0-9]*|litespeed|lshttpd)$") AND match(Image, "(?i)/(sh|bash|dash|zsh|ksh|busybox|nc|ncat|netcat|socat|curl|wget|python[0-9.]*|perl|ruby|id|whoami|uname|hostname|base64|chmod)$")) AND NOT ((isnotnull(CommandLine) AND (match(CommandLine, "(?i)sendmail") OR match(CommandLine, "(?i)/usr/sbin/exim") OR match(CommandLine, "(?i)postdrop"))))
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. Read the full process tree under the worker. A reverse shell (DL-0064), a download into /tmp or /dev/shm, or id / uname right after a burst of PHP memory errors (DL-0066) points to exploitation.
2. Before you restart PHP, capture the worker's memory and the Apache logs. A restart erases the evidence.
3. Patch PHP (8.2.35, 8.3.36, 8.4.27, 8.5.12 or your vendor backport) and restart every worker.

## Known false positives

- PHP mail() runs sh -c sendmail (excluded). Applications that shell out to ImageMagick, git or a converter through sh -c. Baseline them per host.
