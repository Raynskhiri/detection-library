# DL-0046 · DCSync, directory replication requested by an account that is not a DC

**ATT&CK:** [T1003.006](https://attack.mitre.org/techniques/T1003/006/) · **Tactic:** credential-access · **Severity:** critical · **Data:** `windows_event`

Event 4662 on a domain controller with the replication rights GUIDs (DS-Replication-Get-Changes and -All) means someone asked the DC to replicate secrets, the way mimikatz lsadump::dcsync works. Domain controllers do this all the time; a user account should never do it.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.EVENT_LOG
| alter evt_subject_user = json_extract_scalar(action_evtlog_data_fields, "$.SubjectUserName"), evt_target_user = json_extract_scalar(action_evtlog_data_fields, "$.TargetUserName"), evt_object_properties = json_extract_scalar(action_evtlog_data_fields, "$.Properties")
| filter (action_evtlog_event_id = 4662 and (evt_object_properties contains "1131f6aa-9c07-11d1-f79f-00c04fc2dcd2" or evt_object_properties contains "1131f6ad-9c07-11d1-f79f-00c04fc2dcd2" or evt_object_properties contains "89e95b76-444d-4c62-991a-0facbeda640c")) and not ((evt_subject_user != null and evt_subject_user ~= "(?i)\\$$"))
| fields _time, agent_hostname, action_evtlog_event_id, evt_subject_user, evt_target_user, action_evtlog_message
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`wineventlog`
| where (EventCode=4662 AND (match(Properties, "(?i)1131f6aa\\-9c07\\-11d1\\-f79f\\-00c04fc2dcd2") OR match(Properties, "(?i)1131f6ad\\-9c07\\-11d1\\-f79f\\-00c04fc2dcd2") OR match(Properties, "(?i)89e95b76\\-444d\\-4c62\\-991a\\-0facbeda640c"))) AND NOT ((isnotnull(SubjectUserName) AND match(SubjectUserName, "(?i)\\$$")))
| table _time host EventCode SubjectUserName TargetUserName Message
| sort - _time
```

## Triage

1. Treat as domain compromise. Find the source IP from the matching 4624 logon on the DC.
2. Find out which account was replicated (krbtgt, Administrator, trust accounts). If krbtgt: plan a double reset.
3. Remove replication rights from any account that should not hold them (Get-DomainObjectAcl on the domain root).

## Known false positives

- Azure AD Connect (MSOL_ accounts) and some backup or identity products replicate on purpose. Exclude them by name.
