# DL-0047 · Kerberos service ticket with RC4 for a user service account (Kerberoasting)

**ATT&CK:** [T1558.003](https://attack.mitre.org/techniques/T1558/003/) · **Tactic:** credential-access · **Severity:** medium · **Data:** `windows_event`

Event 4769 with ticket encryption 0x17 (RC4) for a service that is not a computer account and not krbtgt. In a domain that uses AES, RC4 service tickets for user accounts with an SPN are what Kerberoasting tools request, because RC4 is the fastest to crack offline.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.EVENT_LOG
| alter evt_subject_user = json_extract_scalar(action_evtlog_data_fields, "$.SubjectUserName"), evt_target_user = json_extract_scalar(action_evtlog_data_fields, "$.TargetUserName"), evt_service_name = json_extract_scalar(action_evtlog_data_fields, "$.ServiceName"), evt_ticket_encryption = json_extract_scalar(action_evtlog_data_fields, "$.TicketEncryptionType")
| filter ((action_evtlog_event_id = 4769 and evt_ticket_encryption = "0x17") and not ((evt_service_name != null and evt_service_name ~= "(?i)\\$$"))) and not ((evt_service_name != null and evt_service_name ~= "(?i)^krbtgt"))
| fields _time, agent_hostname, action_evtlog_event_id, evt_subject_user, evt_target_user, action_evtlog_message
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`wineventlog`
| where ((EventCode=4769 AND lower(TicketEncryptionType)="0x17") AND NOT ((isnotnull(ServiceName) AND match(ServiceName, "(?i)\\$$")))) AND NOT ((isnotnull(ServiceName) AND match(ServiceName, "(?i)^krbtgt")))
| table _time host EventCode SubjectUserName TargetUserName Message
| sort - _time
```

## Triage

1. Many 4769 RC4 requests from one account in a short time is Kerberoasting. A single one may be an old client.
2. Give the targeted service accounts long random passwords or move them to gMSA.

## Known false positives

- Old applications and service accounts still limited to RC4. Fix them (msDS-SupportedEncryptionTypes) and the rule gets quiet.
