# DL-0051 · Service ticket issued through delegation (S4U2Proxy)

**ATT&CK:** [T1558](https://attack.mitre.org/techniques/T1558/), [T1134.001](https://attack.mitre.org/techniques/T1134/001/) · **Tactic:** privilege-escalation · **Severity:** low · **Data:** `windows_event`

Event 4769 with a value in Transmitted Services means a service asked for a ticket on behalf of a user (constrained or resource-based delegation). Attackers who control a computer account with delegation rights use it to impersonate administrators to another host. Useful as a hunt; legitimate delegation creates the same event.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.EVENT_LOG
| alter evt_subject_user = json_extract_scalar(action_evtlog_data_fields, "$.SubjectUserName"), evt_target_user = json_extract_scalar(action_evtlog_data_fields, "$.TargetUserName"), evt_ticket_transmitted_services = json_extract_scalar(action_evtlog_data_fields, "$.TransmittedServices")
| filter action_evtlog_event_id = 4769 and evt_ticket_transmitted_services ~= "(?i)\\w"
| fields _time, agent_hostname, action_evtlog_event_id, evt_subject_user, evt_target_user, action_evtlog_message
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`wineventlog`
| where EventCode=4769 AND match(TransmittedServices, "(?i)\\w")
| table _time host EventCode SubjectUserName TargetUserName Message
| sort - _time
```

## Triage

1. Check the impersonated account. A domain admin being delegated to a server that never needed it is the red flag.
2. Review msDS-AllowedToActOnBehalfOfOtherIdentity on the target service's computer (DL-0052).

## Known false positives

- Web and SQL front ends that use constrained delegation. Baseline which services delegate to which.
