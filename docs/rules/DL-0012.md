# DL-0012 · Microsoft Defender disabled or given exclusions

**ATT&CK:** [T1562.001](https://attack.mitre.org/techniques/T1562/001/) · **Tactic:** defense-evasion · **Severity:** high · **Data:** `process_creation`

Set-MpPreference or Add-MpPreference turns off real-time, behaviour or script scanning, or adds a path, process or extension exclusion. Or the WinDefend service is stopped. Ransomware operators do this right before deploying the payload.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter ((action_process_image_name in ("powershell.exe", "pwsh.exe") and (action_process_image_command_line contains "set-mppreference" or action_process_image_command_line contains "add-mppreference")) and (action_process_image_command_line contains "disablerealtimemonitoring" or action_process_image_command_line contains "disablebehaviormonitoring" or action_process_image_command_line contains "disableioavprotection" or action_process_image_command_line contains "disablescriptscanning" or action_process_image_command_line contains "disableblockatfirstseen" or action_process_image_command_line contains "exclusionpath" or action_process_image_command_line contains "exclusionprocess" or action_process_image_command_line contains "exclusionextension")) or (action_process_image_name in ("sc.exe", "net.exe", "net1.exe") and action_process_image_command_line contains "windefend")
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where (((lower(process_name)="powershell.exe" OR lower(process_name)="pwsh.exe") AND (match(CommandLine, "(?i)set\\-mppreference") OR match(CommandLine, "(?i)add\\-mppreference"))) AND (match(CommandLine, "(?i)disablerealtimemonitoring") OR match(CommandLine, "(?i)disablebehaviormonitoring") OR match(CommandLine, "(?i)disableioavprotection") OR match(CommandLine, "(?i)disablescriptscanning") OR match(CommandLine, "(?i)disableblockatfirstseen") OR match(CommandLine, "(?i)exclusionpath") OR match(CommandLine, "(?i)exclusionprocess") OR match(CommandLine, "(?i)exclusionextension"))) OR ((lower(process_name)="sc.exe" OR lower(process_name)="net.exe" OR lower(process_name)="net1.exe") AND match(CommandLine, "(?i)windefend"))
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. Read the exact setting changed and revert it.
2. Treat the host as compromised until proven otherwise; look at the 30 minutes before for the access path.
3. Check whether the same command ran on other hosts (it often runs fleet-wide before encryption).

## Known false positives

- Exclusions pushed by IT for backup or database software. These should come from GPO or Intune, not an interactive shell.
