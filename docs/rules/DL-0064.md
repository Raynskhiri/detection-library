# DL-0064 · Reverse shell one-liner on Linux

**ATT&CK:** [T1059.004](https://attack.mitre.org/techniques/T1059/004/), [T1059.006](https://attack.mitre.org/techniques/T1059/006/) · **Tactic:** execution · **Severity:** critical · **Data:** `process_creation`

Command lines that connect a shell back to an attacker: bash with /dev/tcp, bash -i, netcat or ncat with -e or -c, mkfifo pipes, socat exec, or Python and Perl socket one-liners. After a web exploit this is usually the first thing run.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter action_process_image_command_line ~= "(?i)(/dev/(tcp|udp)/|\\bbash\\s+-i\\b|\\bnc(at)?\\b.*\\s-(e|c)\\s|mkfifo\\s|socat\\b.*exec:|socket\\.socket\\(|pty\\.spawn\\(|IO::Socket::INET)"
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where match(CommandLine, "(?i)(/dev/(tcp|udp)/|\\bbash\\s+-i\\b|\\bnc(at)?\\b.*\\s-(e|c)\\s|mkfifo\\s|socat\\b.*exec:|socket\\.socket\\(|pty\\.spawn\\(|IO::Socket::INET)")
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. Isolate the host. Take the remote IP and port from the command line and block them at the edge.
2. Find the parent. A web server or PHP worker parent means a web exploit (DL-0063); check the web logs around that time.

## Known false positives

- Admin scripts that test a port with bash /dev/tcp. They do not start an interactive shell.
