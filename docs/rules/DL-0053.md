# DL-0053 · Constrained delegation configured on an account

**ATT&CK:** [T1098](https://attack.mitre.org/techniques/T1098/), [T1134.001](https://attack.mitre.org/techniques/T1134/001/) · **Tactic:** privilege-escalation · **Severity:** medium · **Data:** `windows_event`

Event 5136 changing msDS-AllowedToDelegateTo. The account can then get tickets as any user for the listed services, and the service name in the ticket can be swapped for another service on the same host (for example TIME to LDAP or CIFS).

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.EVENT_LOG
| alter evt_subject_user = json_extract_scalar(action_evtlog_data_fields, "$.SubjectUserName"), evt_target_user = json_extract_scalar(action_evtlog_data_fields, "$.TargetUserName"), evt_attribute_name = json_extract_scalar(action_evtlog_data_fields, "$.AttributeLDAPDisplayName")
| filter action_evtlog_event_id = 5136 and evt_attribute_name = "msds-allowedtodelegateto"
| fields _time, agent_hostname, action_evtlog_event_id, evt_subject_user, evt_target_user, action_evtlog_message
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`wineventlog`
| where EventCode=5136 AND lower(AttributeLDAPDisplayName)="msds-allowedtodelegateto"
| table _time host EventCode SubjectUserName TargetUserName Message
| sort - _time
```

## Triage

1. Check the services listed. Delegation to a domain controller (LDAP, CIFS, HOST, TIME) is as good as Domain Admin.
2. Prefer resource-based delegation scoped to the exact service, and mark admins as not delegatable.

## Known false positives

- Planned delegation for web or SQL front ends. Review with the application owner.
