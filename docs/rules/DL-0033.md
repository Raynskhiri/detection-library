# DL-0033 · In-memory .NET loader runs an offensive tool

**ATT&CK:** [T1620](https://attack.mitre.org/techniques/T1620/), [T1562.001](https://attack.mitre.org/techniques/T1562/001/), [T1027](https://attack.mitre.org/techniques/T1027/) · **Tactic:** defense-evasion · **Severity:** high · **Data:** `process_creation`

Loaders such as NetLoader take a path or URL to a .NET assembly, patch AMSI and ETW, and run the tool from memory so it never touches disk (Loader.exe -path ... -args ...). The tool names usually stay visible in the arguments.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter ((action_process_image_command_line contains "-path" and action_process_image_command_line contains "-args") and action_process_image_command_line ~= "(?i)(https?://|\\\\\\\\|rubeus|safetykatz|certify|sharphound|seatbelt|standin|sharpup|winpeas)") or (action_process_image_command_line contains "netloader" or action_process_image_command_line contains "loader.exe -path")
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where ((match(CommandLine, "(?i)\\-path") AND match(CommandLine, "(?i)\\-args")) AND match(CommandLine, "(?i)(https?://|\\\\\\\\|rubeus|safetykatz|certify|sharphound|seatbelt|standin|sharpup|winpeas)")) OR (match(CommandLine, "(?i)netloader") OR match(CommandLine, "(?i)loader\\.exe\\ \\-path"))
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. The URL in -path is often a local port forward (netsh portproxy, DL-0035) to the attacker's server. Find the listener.
2. Read the -args value. It tells you which tool ran and what it did (DL-0031 for Rubeus, DL-0019 for SafetyKatz).

## Known false positives

- Rare. Some deployment tools accept -path and -args; they do not point at offensive assemblies.
