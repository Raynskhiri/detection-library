# DL-0072 · FortiGate log forwarding turned off or pointed somewhere else

**ATT&CK:** [T1562.006](https://attack.mitre.org/techniques/T1562/006/), [T1562.008](https://attack.mitre.org/techniques/T1562/008/) · **Tactic:** defense-evasion · **Severity:** high · **Data:** `fortigate`

A change under log.* that disables a syslog or FortiAnalyzer target, changes its server, or stops traffic logging. The PEERSTITCH implant (CVE-2025-61624, October 2026) stopped syslog and cleared crash logs to blind the SOC. This is often the last FortiGate event you receive, so pair it with a "device went silent" hunt. FortiGate event log only.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = fortinet_fortigate_raw
| filter _raw_log != null
| alter fg_logid = arrayindex(regextract(_raw_log, "\\blogid=\"?([^\"\\s]*)"), 0), fg_user = arrayindex(regextract(_raw_log, "\\buser=\"?([^\"\\s]*)"), 0), fg_srcip = arrayindex(regextract(_raw_log, "\\bsrcip=\"?([^\"\\s]*)"), 0), fg_ui = arrayindex(regextract(_raw_log, "\\bui=\"?([^\"\\s]*)"), 0), fg_cfgpath = arrayindex(regextract(_raw_log, "\\bcfgpath=\"?([^\"\\s]*)"), 0), fg_devname = arrayindex(regextract(_raw_log, "\\bdevname=\"?([^\"\\s]*)"), 0), fg_logdesc = arrayindex(regextract(_raw_log, "\\blogdesc=\"([^\"]*)\""), 0), fg_msg = arrayindex(regextract(_raw_log, "\\bmsg=\"([^\"]*)\""), 0), fg_cfgattr = arrayindex(regextract(_raw_log, "\\bcfgattr=\"([^\"]*)\""), 0)
| filter (fg_cfgpath ~= "(?i)^log\\." and fg_cfgattr ~= "(?i)status\\[enable->disable\\]|server\\[[^\\]]*->|logtraffic\\[[^\\]]*->disable\\]|upload-option\\[[^\\]]*->") or (fg_cfgpath = "firewall.policy" and fg_cfgattr ~= "(?i)logtraffic\\[[^\\]]*->disable\\]")
| fields _time, fg_devname, fg_logid, fg_user, fg_srcip, fg_ui, fg_logdesc, fg_msg
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`fortigate`
| where (match(cfgpath, "(?i)^log\\.") AND match(cfgattr, "(?i)status\\[enable->disable\\]|server\\[[^\\]]*->|logtraffic\\[[^\\]]*->disable\\]|upload-option\\[[^\\]]*->")) OR (lower(cfgpath)="firewall.policy" AND match(cfgattr, "(?i)logtraffic\\[[^\\]]*->disable\\]"))
| table _time devname logid user srcip ui logdesc msg
| sort - _time
```

## Triage

1. Check when the device last sent logs to the SIEM. A gap that starts with this change is an attacker cleaning up.
2. Re-enable the target, then review admin logins (DL-0068), new admins (DL-0069) and automation objects (DL-0073) from the hour before.

## Known false positives

- Planned SIEM or collector migrations. They change the server address once, with a ticket.
