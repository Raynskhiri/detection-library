# DL-0039 · SQL Server starts a shell (xp_cmdshell)

**ATT&CK:** [T1059.003](https://attack.mitre.org/techniques/T1059/003/), [T1505.001](https://attack.mitre.org/techniques/T1505/001/) · **Tactic:** execution · **Severity:** high · **Data:** `process_creation`

sqlservr.exe starting cmd.exe or PowerShell means xp_cmdshell or a CLR assembly is running OS commands. Attackers reach it through database links, a sysadmin login, or a trustworthy database, and use it to move to the next server.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter actor_process_image_name = "sqlservr.exe" and action_process_image_name in ("cmd.exe", "powershell.exe", "pwsh.exe", "rundll32.exe", "certutil.exe", "bitsadmin.exe", "whoami.exe")
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where lower(parent_name)="sqlservr.exe" AND (lower(process_name)="cmd.exe" OR lower(process_name)="powershell.exe" OR lower(process_name)="pwsh.exe" OR lower(process_name)="rundll32.exe" OR lower(process_name)="certutil.exe" OR lower(process_name)="bitsadmin.exe" OR lower(process_name)="whoami.exe")
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. In the SQL Server logs, find the login that ran xp_cmdshell and any linked server queries (EXECUTE AT, OPENQUERY).
2. Disable xp_cmdshell, remove sysadmin from links, and run the SQL service as a low-privilege gMSA.

## Known false positives

- Maintenance jobs that call xp_cmdshell on purpose. They are scheduled and repeat the same command.
