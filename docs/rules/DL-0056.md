# DL-0056 · Permissions changed on AdminSDHolder or the domain root

**ATT&CK:** [T1098](https://attack.mitre.org/techniques/T1098/), [T1222.001](https://attack.mitre.org/techniques/T1222/001/) · **Tactic:** persistence · **Severity:** critical · **Data:** `windows_event`

Event 5136 changing nTSecurityDescriptor on CN=AdminSDHolder or on the domain object itself. An ACE on AdminSDHolder is copied to every protected group and admin account every hour. An ACE on the domain root can grant DCSync rights. Both are persistence that survives password resets.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.EVENT_LOG
| alter evt_subject_user = json_extract_scalar(action_evtlog_data_fields, "$.SubjectUserName"), evt_target_user = json_extract_scalar(action_evtlog_data_fields, "$.TargetUserName"), evt_object_dn = json_extract_scalar(action_evtlog_data_fields, "$.ObjectDN"), evt_attribute_name = json_extract_scalar(action_evtlog_data_fields, "$.AttributeLDAPDisplayName")
| filter (action_evtlog_event_id = 5136 and evt_attribute_name = "ntsecuritydescriptor") and evt_object_dn ~= "(?i)^(cn=adminsdholder,cn=system,)?dc=[^,]+(,dc=[^,]+)*$"
| fields _time, agent_hostname, action_evtlog_event_id, evt_subject_user, evt_target_user, action_evtlog_message
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`wineventlog`
| where (EventCode=5136 AND lower(AttributeLDAPDisplayName)="ntsecuritydescriptor") AND match(ObjectDN, "(?i)^(cn=adminsdholder,cn=system,)?dc=[^,]+(,dc=[^,]+)*$")
| table _time host EventCode SubjectUserName TargetUserName Message
| sort - _time
```

## Triage

1. Compare the ACL with a known good copy and remove principals that should not be there.
2. On AdminSDHolder, wait for or force SDProp after the fix, then check protected accounts again.

## Known false positives

- Rare. Some identity products need rights on the domain root at install time.
