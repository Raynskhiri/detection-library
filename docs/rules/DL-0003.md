# DL-0003 · Office application starts a shell or script host

**ATT&CK:** [T1204.002](https://attack.mitre.org/techniques/T1204/002/), [T1566.001](https://attack.mitre.org/techniques/T1566/001/) · **Tactic:** execution · **Severity:** high · **Data:** `process_creation`

Word, Excel, PowerPoint, Outlook or another Office app starts cmd, PowerShell, a script host or a LOLBin. This is what a malicious macro or an exploited document looks like on the endpoint. Office almost never needs to do this on its own.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter actor_process_image_name in ("winword.exe", "excel.exe", "powerpnt.exe", "outlook.exe", "msaccess.exe", "mspub.exe", "onenote.exe", "visio.exe") and action_process_image_name in ("cmd.exe", "powershell.exe", "pwsh.exe", "wscript.exe", "cscript.exe", "mshta.exe", "rundll32.exe", "regsvr32.exe", "certutil.exe", "bitsadmin.exe", "schtasks.exe", "msbuild.exe", "wmic.exe")
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where (lower(parent_name)="winword.exe" OR lower(parent_name)="excel.exe" OR lower(parent_name)="powerpnt.exe" OR lower(parent_name)="outlook.exe" OR lower(parent_name)="msaccess.exe" OR lower(parent_name)="mspub.exe" OR lower(parent_name)="onenote.exe" OR lower(parent_name)="visio.exe") AND (lower(process_name)="cmd.exe" OR lower(process_name)="powershell.exe" OR lower(process_name)="pwsh.exe" OR lower(process_name)="wscript.exe" OR lower(process_name)="cscript.exe" OR lower(process_name)="mshta.exe" OR lower(process_name)="rundll32.exe" OR lower(process_name)="regsvr32.exe" OR lower(process_name)="certutil.exe" OR lower(process_name)="bitsadmin.exe" OR lower(process_name)="schtasks.exe" OR lower(process_name)="msbuild.exe" OR lower(process_name)="wmic.exe")
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. Identify the document the Office process had open and where it came from (mail attachment, download, share).
2. Read the child command line and follow any download or new process it started.
3. Search for the same document hash or sender across other mailboxes and endpoints.

## Known false positives

- Business macros that call cmd or PowerShell on purpose. Build an allowlist by document path and signer.
