# DL-0045 · Security descriptor backdoor on WMI, PS Remoting, remote registry or AdminSDHolder

**ATT&CK:** [T1098](https://attack.mitre.org/techniques/T1098/), [T1546.003](https://attack.mitre.org/techniques/T1546/003/), [T1112](https://attack.mitre.org/techniques/T1112/) · **Tactic:** persistence · **Severity:** critical · **Data:** `windows_event`

Nishang and DAMP functions that quietly give an account remote access by editing security descriptors: Set-RemoteWMI, Set-RemotePSRemoting, Add-RemoteRegBackdoor, plus AdminSDHolder and DCSync rights added with PowerView. These are classic domain persistence techniques because nothing new is created, only permissions change.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.EVENT_LOG
| alter evt_subject_user = json_extract_scalar(action_evtlog_data_fields, "$.SubjectUserName"), evt_target_user = json_extract_scalar(action_evtlog_data_fields, "$.TargetUserName"), evt_script_text = json_extract_scalar(action_evtlog_data_fields, "$.ScriptBlockText")
| filter action_evtlog_event_id = 4104 and (evt_script_text contains "set-remotewmi" or evt_script_text contains "set-remotepsremoting" or evt_script_text contains "add-remoteregbackdoor" or evt_script_text contains "get-remotemachineaccounthash" or evt_script_text contains "get-remotelocalaccounthash" or evt_script_text contains "get-remotecachedcredential" or evt_script_text contains "cn=adminsdholder" or evt_script_text contains "-rights dcsync" or evt_script_text contains "invoke-sdpropagator")
| fields _time, agent_hostname, action_evtlog_event_id, evt_subject_user, evt_target_user, action_evtlog_message
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`wineventlog`
| where EventCode=4104 AND (match(ScriptBlockText, "(?i)set\\-remotewmi") OR match(ScriptBlockText, "(?i)set\\-remotepsremoting") OR match(ScriptBlockText, "(?i)add\\-remoteregbackdoor") OR match(ScriptBlockText, "(?i)get\\-remotemachineaccounthash") OR match(ScriptBlockText, "(?i)get\\-remotelocalaccounthash") OR match(ScriptBlockText, "(?i)get\\-remotecachedcredential") OR match(ScriptBlockText, "(?i)cn=adminsdholder") OR match(ScriptBlockText, "(?i)\\-rights\\ dcsync") OR match(ScriptBlockText, "(?i)invoke\\-sdpropagator"))
| table _time host EventCode SubjectUserName TargetUserName Message
| sort - _time
```

## Triage

1. On the target host, review the security descriptors of root\cimv2, the PSRemoting session configuration, and the winreg key.
2. Compare the AdminSDHolder ACL with a known good copy and remove unknown principals.

## Known false positives

- Very rare outside red team work.
