# DL-0020 · Domain admin groups, domain controllers or trusts enumerated with built-in tools

**ATT&CK:** [T1069.002](https://attack.mitre.org/techniques/T1069/002/), [T1087.002](https://attack.mitre.org/techniques/T1087/002/), [T1482](https://attack.mitre.org/techniques/T1482/), [T1018](https://attack.mitre.org/techniques/T1018/) · **Tactic:** discovery · **Severity:** medium · **Data:** `process_creation`

net group "Domain Admins" /domain, nltest /dclist or /domain_trusts, and AdFind trust dumps. Early AD reconnaissance to find who to target and where the domain borders are.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter (((action_process_image_name in ("net.exe", "net1.exe") and (action_process_image_command_line contains "group" and action_process_image_command_line contains "/domain")) and (action_process_image_command_line contains "domain admins" or action_process_image_command_line contains "enterprise admins" or action_process_image_command_line contains "schema admins" or action_process_image_command_line contains "domain controllers" or action_process_image_command_line contains "administrators")) or (action_process_image_name = "nltest.exe" and (action_process_image_command_line contains "/domain_trusts" or action_process_image_command_line contains "/dclist" or action_process_image_command_line contains "/all_trusts" or action_process_image_command_line contains "/trusted_domains" or action_process_image_command_line contains "/dsgetdc"))) or (action_process_image_command_line contains "adfind" or action_process_image_command_line contains "trustdmp" or action_process_image_command_line contains "objectcategory=computer")
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where ((((lower(process_name)="net.exe" OR lower(process_name)="net1.exe") AND (match(CommandLine, "(?i)group") AND match(CommandLine, "(?i)/domain"))) AND (match(CommandLine, "(?i)domain\\ admins") OR match(CommandLine, "(?i)enterprise\\ admins") OR match(CommandLine, "(?i)schema\\ admins") OR match(CommandLine, "(?i)domain\\ controllers") OR match(CommandLine, "(?i)administrators"))) OR (lower(process_name)="nltest.exe" AND (match(CommandLine, "(?i)/domain_trusts") OR match(CommandLine, "(?i)/dclist") OR match(CommandLine, "(?i)/all_trusts") OR match(CommandLine, "(?i)/trusted_domains") OR match(CommandLine, "(?i)/dsgetdc")))) OR (match(CommandLine, "(?i)adfind") OR match(CommandLine, "(?i)trustdmp") OR match(CommandLine, "(?i)objectcategory=computer"))
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. Is this account an admin, and is this host an admin workstation? If not, look at how the session started.
2. Look for other discovery commands from the same session (whoami /all, ipconfig, net view).

## Known false positives

- Helpdesk and AD admins checking group membership. Expect these from admin workstations only.
