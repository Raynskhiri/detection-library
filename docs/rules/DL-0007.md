# DL-0007 · Script host runs a script from a user-writable folder

**ATT&CK:** [T1059.005](https://attack.mitre.org/techniques/T1059/005/), [T1059.007](https://attack.mitre.org/techniques/T1059/007/) · **Tactic:** execution · **Severity:** medium · **Data:** `process_creation`

wscript or cscript runs a .js, .jse, .vbs, .vbe or .wsf file from AppData, Temp, Downloads or Public. This is how many phishing ZIP attachments start their chain.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter (action_process_image_name in ("wscript.exe", "cscript.exe") and (action_process_image_command_line contains "\\appdata\\" or action_process_image_command_line contains "\\temp\\" or action_process_image_command_line contains "\\downloads\\" or action_process_image_command_line contains "\\users\\public\\" or action_process_image_command_line contains "\\desktop\\")) and action_process_image_command_line ~= "(?i)\\.(js|jse|vbs|vbe|wsf|wsh)\\b"
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where ((lower(process_name)="wscript.exe" OR lower(process_name)="cscript.exe") AND (match(CommandLine, "(?i)\\\\appdata\\\\") OR match(CommandLine, "(?i)\\\\temp\\\\") OR match(CommandLine, "(?i)\\\\downloads\\\\") OR match(CommandLine, "(?i)\\\\users\\\\public\\\\") OR match(CommandLine, "(?i)\\\\desktop\\\\"))) AND match(CommandLine, "(?i)\\.(js|jse|vbs|vbe|wsf|wsh)\\b")
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. Get the script file and read it (deobfuscate JScript if needed).
2. Find how it arrived, usually an email attachment or a browser download in the minutes before.

## Known false positives

- Logon scripts or helpdesk scripts copied to a user profile. Allowlist by script hash.
