# DL-0002 · PowerShell download cradle that runs what it fetched

**ATT&CK:** [T1059.001](https://attack.mitre.org/techniques/T1059/001/), [T1105](https://attack.mitre.org/techniques/T1105/) · **Tactic:** execution · **Severity:** high · **Data:** `process_creation`

PowerShell downloads content (Net.WebClient, Invoke-WebRequest, Invoke-RestMethod, BITS) and runs it in memory with Invoke-Expression. This is the classic first-stage loader. Downloading alone is common for admins, so the rule needs both halves.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter (action_process_image_name in ("powershell.exe", "pwsh.exe", "powershell_ise.exe") and (action_process_image_command_line contains "downloadstring" or action_process_image_command_line contains "downloadfile" or action_process_image_command_line contains "downloaddata" or action_process_image_command_line contains "net.webclient" or action_process_image_command_line contains "invoke-webrequest" or action_process_image_command_line contains "iwr " or action_process_image_command_line contains "invoke-restmethod" or action_process_image_command_line contains "irm " or action_process_image_command_line contains "start-bitstransfer")) and action_process_image_command_line ~= "(?i)(\\biex\\b|invoke-expression|\\|\\s*iex)"
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where ((lower(process_name)="powershell.exe" OR lower(process_name)="pwsh.exe" OR lower(process_name)="powershell_ise.exe") AND (match(CommandLine, "(?i)downloadstring") OR match(CommandLine, "(?i)downloadfile") OR match(CommandLine, "(?i)downloaddata") OR match(CommandLine, "(?i)net\\.webclient") OR match(CommandLine, "(?i)invoke\\-webrequest") OR match(CommandLine, "(?i)iwr\\ ") OR match(CommandLine, "(?i)invoke\\-restmethod") OR match(CommandLine, "(?i)irm\\ ") OR match(CommandLine, "(?i)start\\-bitstransfer"))) AND match(CommandLine, "(?i)(\\biex\\b|invoke-expression|\\|\\s*iex)")
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. Pull the URL out of the command line and check its reputation and when the domain was registered.
2. Fetch the payload from an isolated sandbox, not from the endpoint.
3. Check for files written and connections made right after the event.

## Known false positives

- Installers for developer tools that pipe a script from the vendor (for example some package manager bootstraps).
