# DL-0024 · Command started through WinRM remoting

**ATT&CK:** [T1021.006](https://attack.mitre.org/techniques/T1021/006/) · **Tactic:** lateral-movement · **Severity:** medium · **Data:** `process_creation`

wsmprovhost.exe is the host process for PowerShell remoting (WinRM). A shell, a LOLBin or a discovery command under it means someone ran it remotely, for example with Enter-PSSession or evil-winrm.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.PROCESS and event_sub_type = ENUM.PROCESS_START
| filter actor_process_image_name = "wsmprovhost.exe" and action_process_image_name in ("cmd.exe", "powershell.exe", "whoami.exe", "net.exe", "net1.exe", "nltest.exe", "rundll32.exe", "regsvr32.exe", "certutil.exe", "reg.exe", "schtasks.exe", "sc.exe")
| fields _time, agent_hostname, actor_effective_username, actor_process_image_name, action_process_image_name, action_process_image_command_line
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`sysmon` EventCode=1
| eval process_name=lower(mvindex(split(Image,"\\"),-1)), parent_name=lower(mvindex(split(ParentImage,"\\"),-1))
| where lower(parent_name)="wsmprovhost.exe" AND (lower(process_name)="cmd.exe" OR lower(process_name)="powershell.exe" OR lower(process_name)="whoami.exe" OR lower(process_name)="net.exe" OR lower(process_name)="net1.exe" OR lower(process_name)="nltest.exe" OR lower(process_name)="rundll32.exe" OR lower(process_name)="regsvr32.exe" OR lower(process_name)="certutil.exe" OR lower(process_name)="reg.exe" OR lower(process_name)="schtasks.exe" OR lower(process_name)="sc.exe")
| table _time host User ParentImage Image CommandLine
| sort - _time
```

## Triage

1. Find the source IP in Microsoft-Windows-WinRM/Operational and the type 3 logon.
2. Check if the account normally administers this host.

## Known false positives

- Admins and management tools using PowerShell remoting. Baseline the source hosts.
