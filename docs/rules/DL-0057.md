# DL-0057 · Member added to a privileged domain group

**ATT&CK:** [T1098.007](https://attack.mitre.org/techniques/T1098/007/) · **Tactic:** persistence · **Severity:** high · **Data:** `windows_event`

Events 4728, 4732 and 4756 (member added to a global, local or universal group) for Domain Admins, Enterprise Admins, Schema Admins, Administrators and the operator groups. These groups change rarely, so every addition deserves a look.

## Cortex XDR (XQL)

```sql
config case_sensitive = false
| dataset = xdr_data
| filter event_type = ENUM.EVENT_LOG
| alter evt_subject_user = json_extract_scalar(action_evtlog_data_fields, "$.SubjectUserName"), evt_target_user = json_extract_scalar(action_evtlog_data_fields, "$.TargetUserName")
| filter action_evtlog_event_id in (4728, 4732, 4756) and evt_target_user in ("domain admins", "enterprise admins", "schema admins", "administrators", "account operators", "backup operators", "server operators", "dnsadmins", "group policy creator owners", "key admins", "enterprise key admins")
| fields _time, agent_hostname, action_evtlog_event_id, evt_subject_user, evt_target_user, action_evtlog_message
| sort desc _time
| limit 1000
```

## Splunk (SPL, Sysmon)

```
`wineventlog`
| where (EventCode=4728 OR EventCode=4732 OR EventCode=4756) AND (lower(TargetUserName)="domain admins" OR lower(TargetUserName)="enterprise admins" OR lower(TargetUserName)="schema admins" OR lower(TargetUserName)="administrators" OR lower(TargetUserName)="account operators" OR lower(TargetUserName)="backup operators" OR lower(TargetUserName)="server operators" OR lower(TargetUserName)="dnsadmins" OR lower(TargetUserName)="group policy creator owners" OR lower(TargetUserName)="key admins" OR lower(TargetUserName)="enterprise key admins")
| table _time host EventCode SubjectUserName TargetUserName Message
| sort - _time
```

## Triage

1. Confirm with the person who made the change (subject account). If nobody expected it, remove the member and reset the account.
2. Look at the member's recent logons and what they touched with the new rights.

## Known false positives

- Planned admin changes. Match them against change tickets.
